# Code of Conduct

Pithos adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and help people learn. That especially includes newcomers asking basic questions about hardware or Linux. Harassment and personal attacks aren't tolerated.

Report concerns privately to the project maintainer (Bubo). *(Contact address TBD before public launch.)*
